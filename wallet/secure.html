Create your wallet

Two secrets: a password and a recovery phrase. They do different jobs

A long, unique password

4 or more random words, or 16+ characters from a manager. Never reuse one

Recovery phrase on paper

Settings › Security › Recovery phrase

Write it by hand, check every word, and do it somewhere private

Two copies, two places

Fires and moves happen. A steel plate survives both

Test your backup

Restore with a tiny amount before you move real money in

Passphrase? Back it up too

If you add the optional 25th word, it is part of your wallet. Without it the same phrase opens a different, empty wallet, and it cannot be recovered. Keep it apart from the phrase

Encrypted backup file

Settings › Backup and export

A handy extra that needs your password. It doesn't replace the paper

Do

  • Write it on paper, by hand
  • Keep it where only you can reach it
  • Tell someone you trust where it is, not what it is

Never

  • Photograph it or save it in notes, email or cloud
  • Type it into a website, form or support chat
  • Share it with anyone, including "support"
Sillet and Raton will never ask for your phrase. Anyone who does is scamming you

If something goes wrong

Act in this order

Lost or broken device

Funds are fine. Install Sillet, choose Restore and enter your phrase

Phrase or wallet exposed

New wallet on a clean device, move everything now. A new password won't help

Sent to a scammer

It can't be undone. Save the tx id, report it, and ignore anyone offering recovery

Forgot your password

Restore with your phrase and set a new one. Without both, nobody can help

How Sillet protects you

What we built to keep your keys safe, and one honest caveat

Your recovery phrase is encrypted

Built

The phrase is encrypted with AES-256-GCM. The key comes from your password through scrypt with a random salt, which makes guessing slow. Nothing readable is written to disk

Device lock on Windows

Built

By default the vault file is also wrapped with Windows DPAPI for your user account, so a copied file is useless on another user or PC. You can turn this off in Settings

Biometric unlock

Built

Windows Hello on desktop and the Android Keystore on phones. Your password is never sent anywhere. Only a secret protected by the system is used to unlock it locally

Keys stay on your device

Built

Private keys are derived and used to sign on your device only. A signed transaction is the only thing sent to the network

Screen and clipboard protection

Built

You can hide balances, block screenshots and screen capture, blur the window when inactive and clear the clipboard after copying

Auto lock and unlock slowdown

Built

The wallet locks after the time you choose, on minimize or when the system locks. Repeated wrong passwords make each attempt wait longer

Not independently audited

Open

All of the above is our own work and has not been reviewed by an outside firm. Until it is, treat it as unaudited

Things worth knowing

Plain facts that are easy to miss and that you should know before you rely on any wallet

A public blockchain is public

Know this

Anyone can see the balance and history of any address. Sillet cannot hide that. Change addresses and separate accounts help, but they do not make you anonymous

Nodes see what you ask

Know this

A public node learns your IP and which addresses you query. Use Tor or a proxy in Settings, or your own node, if that matters to you

Services you open are not ours

Know this

Swaps and buying run through Exolix, MoonPay, Ramp, Transak, Buda or Orionx. Their terms, fees and identity checks apply, not ours

Rotating receive addresses are optional

Know this

Turn them on in Settings. Bitcoin, Litecoin and Dogecoin then show a fresh address each time the last one receives a payment. Old addresses keep working and their funds count in your balance. To find them Sillet asks the explorer about each address of your wallet in order, so it makes a few more requests. EVM networks, TRON and Solana use one address per account, so use another account if you want a different one

The NFT view talks to Blockscout

Know this

It is off until you turn it on. When on, your EVM address is sent to Blockscout to list your ERC-721 and ERC-1155 items on Ethereum, Base, Optimism, Arbitrum, Polygon and Gnosis. Images are a separate switch, and they load straight from the host that serves each one, so they do not go through your proxy or Tor. It is read-only: you cannot send NFTs from Sillet

Prices and values are estimates

Know this

Fiat values come from third parties and can be late or wrong. Custom tokens show no price on purpose

No analytics and no accounts

Good to know

Sillet has no sign up, no analytics, no advertising identifiers and no crash reporting. Because we hold no account data, there is nothing for us to export or delete for you

Storage and updates

What is kept, where, and how new versions arrive

On your deviceThe encrypted vault, settings, contacts, activity history, price alerts, notification history and cached news
Your passwordIt is not kept in readable form. If you turn on biometric unlock, a protected copy is held by Windows Hello or the Android Keystore
Removing itDelete the wallet inside Sillet to remove its vault from that device. Uninstalling the app alone can leave files behind, so delete the wallet first
NotificationsCreated on your device. On Android a background service checks the same public sources so alerts work when the app is closed. We run no push server
UpdatesWindows downloads a new version from raton.fun and checks its SHA-256 before using it. Android and Linux only tell you a new one exists
ChangesIf we add a service or change what is sent, this page is updated before the release that does it

Known issues and limits

Things that are not as good as they should be, listed so you can decide with full information

No independent audit yet

Open

The code has not been reviewed by an outside security firm

Some incoming payments have no transaction id

Open

Detection still starts from a balance change. The id and sender are then looked up, but native coin payments on EVM networks and combined payments have none. Background alerts watch your main account only

Hardware wallets are watch-only

Open

You can view balances and receive, but not sign with the device

Your IP is visible unless you use Tor or a proxy

Open

Nodes and APIs can see your IP and which addresses you ask about. Turn on Proxy or Tor in Settings to hide it

Custom tokens have no price

By design

Custom tokens are added by contract address and show no price. Tokens with unusual behavior, such as fees on transfer, may show wrong amounts. The NFT view is read-only and covers six EVM networks. NFT images load straight from the host that serves them, not through your proxy

Android updates are manual

By design

Android only notifies you about a new version and you install it yourself. Linux works the same way. Only Windows can update itself

Public nodes can be slow or rate limited

Open

Because we use free public nodes by default, balances may occasionally load slowly or fail. Pull to refresh to retry or point a network to your own node

Dogecoin depends on one free service

Open

Dogecoin uses BlockCypher, which limits free requests. When the limit is hit, Dogecoin may not load for a while

How nodes are chosen

Where your balances and transactions come from and what happens when one is down

Public by defaultSillet does not run its own servers for blockchain data. It talks to public nodes and open APIs, so there is no Raton backend that sees your wallet
Ordered listEvery EVM network has three endpoints in a fixed order. For example Ethereum uses publicnode, then dRPC, then LlamaRPC. Solana uses the official endpoint and publicnode. Bitcoin uses mempool.space then Blockstream
FailoverA request goes to the last endpoint that worked. If it times out or the connection fails, the next one is tried automatically, and the one that answers becomes the new first choice
What does not fail overIf a node answers but rejects a request, for example a transfer simulation that fails, that answer is shown to you instead of silently asking another node
Single provider networksTRON uses TronGrid, Litecoin uses litecoinspace.org and Dogecoin uses BlockCypher. If these are down, those networks cannot load until they recover
Why theseThey are free, well known, work without an account or API key, and follow the standard JSON-RPC or Esplora formats. We prefer a mix of independent operators so one outage does not stop a whole network
Checks before signingTokens: the contract decimals are read on-chain and the send is cancelled if they differ. TRON: the node built transaction is checked against what you asked for and its hash is recomputed locally. Signing always happens on your device
Using your own nodeIn Settings, Network privacy, you can set one or more endpoints per network. When you do, that network uses only your node and never falls back to ours. Plain http is accepted only for localhost and private addresses
Proxy and TorYou can route all connections through a SOCKS5 proxy such as Tor or an HTTP proxy. Sillet asks the proxy to resolve names, so your DNS requests are not leaked. If the proxy is down, requests fail instead of going out directly
